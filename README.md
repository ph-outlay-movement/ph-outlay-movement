# PH Outlay Movement

**Outlay** shows how the money for a Philippine government project moved: from the President's budget proposal, through the House, the Senate and the bicameral conference, into the signed budget law, then to the winning bid, the project's status, the Commission on Audit's findings and any case filed.

Every number links to its official source.

> An independent citizen project. Not affiliated with the Philippine government.
>
> Outlay shows public records. It does not accuse anyone. An "indicator for review" means a record is worth a closer look, not that anyone did something wrong.
